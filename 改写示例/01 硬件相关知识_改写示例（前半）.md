## 前言

装过台式机的朋友，大概都体验过挑选主板、CPU、显卡等配件时的纠结；哪怕是电脑小白，多半也刷到过“5060”之类的配置字眼。

这篇博客不想去卷各大品牌的跑分对比，只想用通俗的语言，带你搞懂每个部件到底是干嘛的，以及如何判断好坏——**防止去电脑城或者网购时，被黑心老板当肥羊宰。** 若读完有兴趣了解更多，请搜索硬件茶谈相关视频。

交代一下本篇的讲法。笔者不按百科顺序讲，而是按装机时真正会遇到的决定顺序来：**主板 → CPU → 内存 → 显卡 → 硬盘 → 电源**。理由很简单——主板最先锁死你能装什么，电源最后决定这一堆能不能安心干活。每个部件都按“它是什么 → 新手该看什么 → 怎么防坑”三步走，赶时间的话也可以只看每节的防坑部分，但很多坑是前面埋下的，笔者建议按顺序读完。

## 主板

主板主板，顾名思义，就是一块板子，你的绝大部分电脑配件都安装在上面，外设一般与主板相连。（使用独立显卡时，显示器需连接至独立显卡的视频输出接口，而非主板的显示输出口）

### 为什么第一个讲它

因为它是新手装机里最容易“一步错、步步错”的部件。CPU 能不能插、内存买 DDR4 还是 DDR5、以后能不能加硬盘，全在你最先定下来的主板身上锁着。现实里不少人是先挑好心仪的 CPU，回头才发现主板不兼容，只能整单重来。所以笔者的建议就一句：**先定平台（Intel 还是 AMD），再定芯片组，最后才挑具体型号。**

> **【建议补】** 你第一次装机时在主板/CPU 上纠结或翻车的真实经历，一两句即可。这类细节是“人味”最贵的部分，我编不了，也不想替你编。

### 基础功能
（可以理解成军事基地）
1. 提供场地（即物理载体，否则你的配件怎么固定呢）
2. 后勤保障（即供电，主板上有复杂的供电模块（VRM））
3. 交通公路（即数据通路，主板上密密麻麻的电路）

### 新手只需要看三件事

主板知识能写一本书，但新手真正要操心的只有三件：

1. **CPU 接口对不对**：Intel 和 AMD 主板不互通，而且 Intel 换代数就换接口。下单前确认主板页面写的“支持第 X 代”。
2. **内存代数**：DDR4 还是 DDR5。这条和 CPU 是联动的，选错了内存条根本插不上。
3. **芯片组档次**：Intel 的 H/B/Z 系列、AMD 的 A/B/X 系列。笔者推荐多数用户直接选 B 系列（Intel）或 B 系列（AMD）；预算有限选入门级；要超频或扩展再考虑 Z/X。

> 为什么推荐 B 系：它刚好卡在“该有的都有、用不到的不加钱”的位置。Z/X 多出来的超频和扩展性，对不折腾的用户基本是花钱买心安；入门级则往往砍在供电和接口上。这笔账，笔者觉得没必要替老板省。

**一句话防坑**：别只看“支持 13 代”这种宣传语，以主板官网的 CPU 支持列表为准。

非常重要的配件，沿用刚才的军事比喻就像将军，负责战术计算、核心决策 ~~（怪不得人家中文名叫中央处理器）~~。总而言之，所有硬件的活儿都要听它调度。

### 核心数与主频：别只看数字

虽然从外表看是一块方形基板，但其内部集成了多个核心和缓存等复杂电路。“双核”、“四核”就是指它的核心数。

很多人下意识觉得“核心越多越快”。**这个直觉一半对、一半是坑。** 在架构相同的前提下，可以套一个粗暴公式：**性能 = 核心数 $\times$ 主频**（只是极端简化的类比）。$10 \times 1 < 1 \times 100$ 的道理大家都懂，所以才有“主频”这个概念——它是 CPU 内部数字信号每秒震荡的次数，也就是它干活的速度。为了防止“核心多但个个慢”的情况，主频就是那个平衡项。

另外两个看评测会经常撞见的概念：

- **大小核**：高性能核心 + 能效核心混搭（Intel 叫混合架构），兼顾性能与功耗，Windows 11 有针对优化。
- **线程数**：能同时处理的任务数。8 核 16 线程，意味着每个核都有同时干两件事的潜力。

但要注意：核心多、主频高 ≠ 一定强，实际是很复杂的综合平衡，最终看评测。那新手怎么快速判强弱？实用办法是看代际和实测，下面讲。

### 常见型号：别被 i7 三个字母吓到

两家厂商在主流消费市场都很有默契地把产品分成了 3、5、7、9 四个档次（类似宝马的3系、5系、7系）：

1. **入门/办公**：i3 / R3（注：AMD 的 3 系列近几年在零售市场存在感较低）
2. **主流游戏/高性价比**：i5 / R5 / Ultra 5（目前两家都在打架的主战场）
3. **高端生产力/发烧友**：i7 / i9 / R7 / R9

### 防坑指南

**不要盲目迷信数字！并不是叫 i7 就一定强于 i5。** 电子产品买新不买旧，隔代如隔山。拿好几年前的老旧 i7 去碰瓷今年的最新款 i5，只会被沦为路边一条。但具体需结合性能评测判断，并非每一代都有质的飞跃。

至于之前让人诟病的 i9-13900K / 14900K 闪退风波，懂的都懂，新手不碰顶配基本踩不到这个雷，在此不作展开。

然后是最实用的一节：**看懂型号名字**。以 Intel i9-13900K 为例：i9 是档次，13 是指第 13 代，900 指性能档次（同代数字越大越强），K 是后缀。AMD 以 Ryzen 7 7800X3D 为例：Ryzen 7 对应档次，7800 中的第一个 7 代表 7000 系列代际，第二位的 8 代表该系列里的中高端性能位阶，X3D 为后缀。

后缀是什么意思，直接查表——这张表才是选购和防坑的核心：

| 厂商        | 后缀      | 解释与建议                                   |
| --------- | ------- | --------------------------------------- |
| **Intel** | **无后缀** | 自带核显，不支持 CPU 倍频超频（但支持内存 XMP 超频）、日常用最省心。 |
| **Intel** | **K**   | 性能最强，支持倍频超频，但发热大、需要好散热。                 |
| **Intel** | **F**   | 砍掉了内置显卡。**性价比最高**，但必须搭配独立显卡使用。          |
| **Intel** | **KF**  | 既能超频又没有核显。游戏发烧友最爱，性价比高。                 |
| **AMD**   | **无后缀** | 功耗低、发热小。性价比极高，以当前AM5平台为例，通常自带基础核显。      |
| **AMD**   | **X**   | 官方帮你“超频”好了的型号，性能比无后缀略强。                 |
| **AMD**   | **X3D** | **游戏神器！** 玩游戏的帧率极高。                     |
| **AMD**   | **G**   | 处理器内置了性能较强的核显。**不买独显**也能流畅玩轻度游戏。        |

### 装机注意事项

1. 注意与主板是否匹配，这两家CPU主板不互通。
2. 有防呆设计（防止你装反），所以发现放不进去时，请去检查是不是没有对准，不要大力出奇迹弄坏针脚。
3. 注意撕膜，CPU散热器（即风冷 or 水冷）底座有层膜，不撕无法散热，CPU温度会异常。
4. CPU 表面必须涂抹适量导热硅脂，这玩意 *“当你觉得少了点“* 说明刚好，笔者一般是九点涂法（点九个小点）。
5. 如果买了带有 **F** 尾缀（如 i5-14400F）或购买不带核显的AMD处理器（如所有非 G 后缀的 AM4 平台 Ryzen，以及 AM5 平台的 F 尾缀型号如 R5 7500F），**必须要额外购买独立显卡** 且显示器与独立显卡连接，否则无法亮屏。

补充一句：第 5 条是新手装机最常见的事故，没有之一。

## 内存条（RAM）

笔者写下此篇时，由于AI的原因，内存条和金条一样贵，令人感慨——所以下面你会看到笔者反复强调“先保容量”：预算就这么多，得花在刀刃上。

> **【建议补】** 如果你或朋友正好在这波涨价里买过内存，把真实价格和当时的心路历程写进去，比任何比喻都有说服力。

### 它到底是干嘛的

沿用军营比喻，内存条类似传令兵：把将军马上要用的文件和命令临时放在身边，方便随时调阅。**务必注意，RAM 断电就会失去一切存储信息**，和硬盘（SSD/HDD）不同。

内存条（RAM）比较重要的概念，笔者认为是世代代号（DDR）和工作频率（MHz）。它们决定了内存与 CPU 之间的数据传输带宽。带宽越大，数据送达 CPU 的速度就越快，不仅能防止 CPU 闲置“发呆”，还能显著提升游戏的最低帧（1% Low 帧），让游戏画面减少突然的卡顿。至于大家测评里看到的所谓时序，就是指内存条响应 CPU 指令的延迟时间，具体过程极其复杂。[^1]

[^1]: 内存条还有颗粒和超频等知识，笔者不在此讲解，因为笔者认为这并不适合电脑小白。

> [!info]- 点击展开：时序小科普
> 时序是一组延迟参数（如CL-tRCD-tRP-tRAS），其中CL最为关键，数值越小，内存响应速度越快。但需结合频率综合判断延迟。DDR5 的 6000 ，6400 ，6800 MHz 笔者推荐的甜品时序分别为 CL 30，32，34。

### 作用

1. 临时数据中转站：由于下文介绍的硬盘（SSD/HDD）速度较慢，CPU来不及处理的或者要随时调用的数据，就先暂时存放在此。
2. 决定处理多任务的能力：相信大家买手机都有 “16+512” 这种选项，虽然手机厂商在你那512GB存储空间不够时也会说 “内存不足” ，但请读者理解，电脑上的内存就是指前面的 16，大家之所以要买大内存的手机，应该是为了游戏，微信，QQ，挂后台不被手机 “杀” 了，正是因为内存条在后台把这些程序的运行数据同时 “兜住” 。

### 怎么买

原稿这里分成了“产品迭代”和“小贴士”两块，信息其实是一件事：买。笔者把它们按优先级合成一张清单：

- **先看容量**：日常使用 16 GB 够用；生产力、游戏建议 32 GB 起步。不要为了频率把 32 GB 换成 16 GB，得不偿失。
- **再看世代**：DDR5 是大多数人现在的选择（注意和主板、CPU 的适配性）；预算低或老电脑升级可选高频 DDR4；低频 DDR4（如 2133/2400 MHz）及更早的 DDR3，如果不是你主动要买，那就是被老板坑了。
- **最后看频率**：DDR5 时代 6000–6800 MHz 完全够用。
- **两根内存千万不要买工作频率不同的！** 电脑只会向下兼容，等于白花钱。
- 装机优先插主板标注为 DIMM_A2 和 DIMM_B2 的插槽（通常是从 CPU 侧数第 2 和第 4 个插槽），具体看主板说明书，**绝对不能乱插**。
- 防呆设计是防止装反，不是“用力就能进”，别大力出奇迹。
- 开机狂按 Delete 进 BIOS 开启 XMP / EXPO（不同主板方式可能不同，如联想为 F1，惠普为 F10，不确定可询问客服 or 售后），否则高频内存白白降频。
