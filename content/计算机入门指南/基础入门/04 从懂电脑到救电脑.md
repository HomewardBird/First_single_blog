## 懂电脑：

很多人电脑买回来，但是什么都不懂，不仅用久了变卡变慢，效率还很低，本章的目的就是为了解决三件事：回本！回本！还是 ** 的回本！（毕竟不能让几千的电脑发挥几百的作用）

### 提升效率关键

电脑买回家，除了基本的打游戏看视频外，笔者认为最重要的就是生产力了，大型专业软件，和一些不适配手机的网页，只有电脑才能干的舒服，顺心，但如何有一个良好的使用体验呢？那就是——快捷键。

### 新软件基本设置

新软件到手，一般不能先急头白脸开始用，最好先进行一些设置，但是修改需耐心，心急则伤机。（软件多种多样，笔者仅在此推荐我的一般操作，不会针对某一软件详细说明）[^1]

#### 下载时：

首先尽量找官网或 GitHub 下载，确保安装包的纯粹，但假如是破解版，要上各种下载站下载，且无法确定下载站是否纯粹时，选择**普通下载**，千万别选高速下载等屁话，本质上就是捆绑其他软件。至于在部分网页看到繁多的版本选择，笔者建议，对于普通用户，Windows 11 系统直接无脑x64 版本。

下载完后关注一下安装包大小，一般来说，基础的，需要安装的小工具（如安装版 7-Zip, Everything, Notepad3）一般大小会小于 20 MB，而日常工具通常在 50 ~ 500 MB，若过小大概率有问题。（务必远离恶意和捆绑软件，否则电脑上全是传奇）
#### 安装时：
建议找到自定义安装或安装位置类似的文字，找到安装路径，将最前面的 C: 换成 D: 如下图所示，（务必不要删除后面那一长串，路径最好不要有中文，纯英文是最稳妥的）到时候会自动在 D 盘中出现几个文件夹，方便管理。 

假如是便携版（不用安装），建议全放在同一个文件夹中。再次强调，安装时请谨慎选择，不要一路下一步，不然可能会被捆绑安装全家桶，或者强制修改你默认方式。~~（你也不想你花重金购买的电脑却被流氓软件狠狠玷污了吧）~~

### 安全问题：
（观前严肃提示，本章内容十分重要，若有可补充之处，欢迎大家在评论区补充）

个人信息泄露、账号接管、勒索软件和钓鱼诈骗的成本正在降低。防病毒软件与系统防护很重要，但真正决定风险上限的，往往是密码、下载、链接、授权与备份等日常操作习惯。这真的非常非常重要，笔者部分操作可能会过分谨慎，大家仁者见仁即可。
#### 信息安全方面：

woc，密码给我设好了啊！！

Chrome，Edge 等浏览器自带的密码生成器挺好用的，但假如你希望浏览器管理密码的话 Bitwarden 挺好。而且可以注册一个邮箱专门注册一些看起来不对劲但比较需要的网站（我个人是有三个邮箱，一个娱乐加聊天一个学习一个垃圾箱。但是按照严肃程度分类也可以，比如一个邮箱专门注册登录，一个负责银行卡等极其私密管理，不公开等，看你操作习惯）当然有些垃圾网站甚至拿临时邮箱都能注册，不过多赘述。

扩展是高权限软件，它可能读取当前网页内容、修改网页、访问剪贴板或代替你点击。只安装确实需要的扩展，优先选官方开发者或长期维护项目。安装前看开发者、用户量、更新记录和所申请权限。对读取和更改你访问的所有网站数据，管理下载，访问剪贴板等广泛权限尤其谨慎，并定期删除闲置扩展。而且要注意拓展（其实不仅仅是拓展，而是所有软件）的设置，防止出现之前类似沉浸式翻译插件带来的隐私泄露问题。

还有类似什么日入百刀，虚拟币这种肯定是骗子，要么偷信息要么拿你电脑挖矿要么要割你腰子（雾），像约跑这种同理（tg 诈骗最严重，且无法挽回）

双重验证能显著降低密码泄露后被直接登录的风险。所以优先使用验证器 App、通行密钥或硬件安全密钥，并妥善保存恢复码。不要把验证码、恢复码或登录确认轻易请求交给任何人。但是由于中国手机号的特殊性，假如一些比较敏感的网站建议使用邮箱辅助或其他方式，不然 Facebook 这种网站可能直接封你号。

#### 电脑安全方面：

.exe、.scr、.bat、.cmd、.ps1、.vbs、.js、.msi、.lnk 别瞎点，小心鬼图糊你脸上，硬盘数据全没了。收到 .zip、.rar、.7z 等压缩包时，先确认来源和内部文件类型后再解压。认识常见后缀，如书本多为pdf或epub，音乐多为mp3，flac，wav这种（<font color="#ff0000">务必打开查看文件拓展名！务必打开查看文件拓展名！务必打开查看文件拓展名！</font>不然可能会遇见哈利波特.pdf.exe）

还有就是老生常谈的话了，不点击来路不明的邮件附件、短信链接、弹窗广告或聊天文件，尤其是要求立刻登录，领取奖励，安装插件的内容。不要滥给权限。浏览器、安全软件、常用办公/解压/播放器及时更新，其他笔者认为没必要频繁更新，至于系统，这玩意仁者见仁吧，没必要过分担心，危险操作前设置系统还原点。（就是由于 Windows 屎山代码，还原有概率失败）

>[!info]- 较为高级的安全知识：
>特别注意：常见阅读和媒体文件通常不是直接可执行程序，但仍应核对来源、扩展名和打开方式；不要因为它显示为 PDF、EPUB 或 MP3 就默认可信。系统和阅读器、播放器也应保持更新。类似 FFmpeg 流媒体漏洞 CVE-2026-8461 | PixelSmash 这种，极难防范。
>
>所以说，并非所有风险都能靠经验识别。有些攻击利用播放器、浏览器、解压软件或阅读器自身漏洞，恶意内容的扩展名、图标甚至来源看起来都可能正常，文件被自动预览、生成缩略图或解析时就可能触发。普通用户无法可靠肉眼验毒。因此，除谨慎下载外，更关键的是保持系统和常用软件更新、减少不必要的软件和自动预览、以普通权限使用电脑，并做好可恢复的离线备份。安全的目标不是保证永不出事，而是即使某次防线失效，损失仍可控。


#### 网站安全：

官网一般来说是安全的，但首先要确保你找到的是官网。要看域名的真伪，如`accounts.google.com` 和 `accounts.google-security.top` 和 `g00gle.com`。第一个是真的，后两个就是假的

>有趣的冷知识：谷歌财大气粗，把类似域名全买了，像 Gooooogle 这种也是真的，但是这是特例，保持谨慎，感觉不对一律当钓鱼网站。

网址组成：https:// 域名主体 .com / 后面的是具体路径，如果域名主体是陌生的词或奇怪的后缀，建议仔细检查，确认有问题后关闭。

#### 文件安全：

数据无价，先不说你辛辛苦苦打的游戏账号，存的精品视频，漫画这种。有些在神秘群聊或其他隐秘途径中获得的文件，若丢失极难找回，所以文件安全极其重要，不管手机电脑。

但其实真正要做的不多，更多是一种习惯，定期备份重要文件，最好遵循“本机一份、独立存储一份、云端或异地一份”的思路。备份盘不应长期一直连接电脑，以降低勒索软件连同备份一起加密的风险。

定期清理不再使用的软件、浏览器扩展和不明启动项，权限只授予确实需要的应用。其他似乎也没啥了，如上就是我认为对于大部分人来说最重要的安全使用习惯。

### 解决问题：

各种软件使用下来大概率都会遇到报错或和教程不同的地方，以及多种多样的报错也是 Windows 系统不得不品的一环，解决方法笔者推荐按照以下步骤

**第一步，提取信息**

环境是什么：什么操作系统（Windows11 / macOS）？什么软件版本？

做了什么操作：在崩溃前最后一秒，你点击了什么、修改了什么？

现象是什么：有没有错误代码？是闪退、无响应，还是弹窗报错？（若有，找到带有 Error、Failed、Exception、Warning 的一大坨，如果有弹窗，优先复制完整文字，尤其是错误代码、错误名称、失败的操作、文件路径、模块名和时间）

**第二步：搜索**

若有错误代码，原模原样复制到搜索引擎，大概率能解决。（新手可以优先排查运行库缺失，上官网下载对应运行库就行了）

若无错误代码（如具体操作不会，PR 导入视频无声音）可先在搜索引擎中搜索
，若无满意内容，翻译成英文再搜索试试。

结果众多时优先关注官方文档，其次是 Reddit, Stack Overflow, CSDN等，倘若这几个都没有，可以去哔站，油管，个人博客碰运气（其实个人博客一般都很好，只是可遇不可求）。

面对大量结果时，除了按上述所说按来源分类，还可以优先关注最近发布的内容。警惕洗稿内容，在不确定时学会交叉认证，万万不可盲信 AI。

提问内容表达要专业，如 Premiere Pro 24.1 导入 MP4 后无音频    Windows 11 23H2    导入的文件为 XXX.mp4，其他 MP4 正常    报错：Audio conforming failed / 错误代码……（关键词用一个空格隔开，为了展示清楚，此处统一用四个空格）

也就是 软件名 + 版本 + 完整错误代码/完整报错句 的格式。


**第三步：修改**

控制变量法，一次改一个。如麦克风在游戏中无声音，先测硬件，使用系统自带录音机检查，若无，检查驱动，插头，若有，下一步，测系统是否允许麦克风权限等等等。不要一次性全改完再检查。<font color="#ff0000">危险操作先备份！危险操作先备份！危险操作先备份！</font>比如假如要修改系统设置，请搜索创建还原点，创建后进行操作，出问题可以一键还原。（就是由于 Windows 屎山代码，还原有概率失败）

**第四步：求助**

若上面步骤都不行，就可以求助 AI 或认识的人，提问格式建议如下

- **目标**：我想要实现什么/解决什么
- **环境**：我的系统/软件版本
- **报错**：具体的报错文本或截图描述（用截图软件而非星露谷式截图，电脑蓝屏这种除外 ）
- **已尝试过的方案**：我尝试了 A 和 B，但结果是 C。（不要南辕北辙，比如你只想两个电脑间互传文件，然后去摸索如何搭建一个 FTP 服务器，所以目标及其关键。问 AI 时可以询问具体原理，问人类时除非对方时间充裕且关系较为密切，不然不建议，因为解释原理涉及内容大多太繁杂了）
- **诉求**：请帮我分析可能的原因，并给出排查步骤
- **表达感谢**（礼貌用语很重要啊！）
