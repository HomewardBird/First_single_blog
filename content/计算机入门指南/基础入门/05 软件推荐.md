## 下载器

骚年，你认为浏览器直接下载的速度难以接受吗，那就使用它的力量吧——下载器

先简单介绍一下下载器原理，下载器会先获取文件总大小，然后把文件虚拟分成多段，同时建立多个网络连接（线程）去请求服务器的不同部分。假如听不懂也没关系，比如本来浏览器每秒能下载 10 MB 的内容，1 GB 的文件需要接近 100 秒，而下载器就是把这 1 GB 分割成 8 块，每块 125 MB，同时下载，这样只要 12.5 秒就能完成任务，导致加载速度被大幅度增加。感兴趣者可[点击跳转到知乎文章](https://zhuanlan.zhihu.com/p/560791482)

笔者个人使用的下载器为 Neat Download Manager，简称 NDM，这是一个免费开源的软件，请读者运用先前教给大家的网页判断方法，打开搜索引擎后自主搜索官网，随后进行比对。[官网地址](https://www.neatdownloadmanager.com/index.php/en/)

安装完后点击右上方浏览器 Browsers，选择你使用的浏览器进行插件安装，其他设置不推荐改动。假如你在浏览器上下载极慢甚至无法下载，暂时关闭 NDM 插件可以解决问题，但是这个问题出现概率极低，日常使用可以忽略。

### 记事本替代

在之前的[[02 你该知道的电脑认知#站长怎么这么坏，给我看乱码]]中提到了 Notepad3，这就是很好的一个替代软件，在软件内部还能一键夺舍，把所有打开记事本的操作换成打开此软件。‘

这个软件优点是内存开销小，支持语法高亮，完整支持 PCRE 正则表达式，文本清洗/行操作方便快捷，自动选定合适编码，大文件加载 （>100MB）等

虽然这个软件确实存在一定缺点，如主线项目维护趋于停滞，高版本 Scintilla 优化未跟进，而且对超大文本（>1 GB）的加载能力受限于 Win32 内存映射机制。但是我认为对普通人来说完全够用了。没必要为了未来极小概率需要的需求，而在找软件时踌躇不定，最后费尽心思下到最完美的软件后发现只用上了基础内容。

### 软件卸载

设置之中卸载，能力还不够强，假如遇见流氓软件，注册表卸载不干净，怎么办呢？HiBit Uninstaller 就是笔者找到的解决办法。

使用非常简单，下载完后在页面中选择要卸载的应用，双击，软件本体卸载程序执行后，选择高级扫描，备份，随后删除就能清理干净注册表，假如发现误删注册表，也可以使用备份一键复原（具体位置在右上角工具，报告和备份管理器中，快捷键为 B）

那肯定有读者会问了，主播主播，有些软件莫名其妙就给我装上了，哪些是要删除的流氓软件呢？这里给大家一些笔者自己认为所谓的流氓软件：

- 传奇系列，法师控制强，冰霜秒全场！
- 各种国产软件全家桶，如 2345,360等
- 一些收费类工具软件，如 PDF 编辑，压缩等非常基础的工具，除非像 Acrobat 这种专业软件，不然都是有免费平替
- 本地部署 DeepSeek 等无意义弱智 AI 软件（这种软件甚至很多要你钱）
- 功能重复的软件，如多个杀毒软件，多个压缩软件，这种软件一个就够了

还是老样子，请先自己寻找官网再对比是否寻找正确，[官网地址](https://www.hibitsoft.ir/Uninstaller.html)，[GitHub 下载](https://github.com/XQGIN/Hibit-uninstall/releases/tag/V4.0.10)。

### 截图工具：

Windows 自带的截图不能说方便快捷，只能说勉强够用，而且很多功能都没有，所以这里给大家推荐 Pixpin，最大的优点是悬浮图，长截图，美观的 UI 等。老样子，自己先搜索后比对。[官网地址](https://pixpin.cn/)

此软件有免费版和付费版，笔者用下来这么长时间，免费版完全够用，截图快捷键为 `Ctrl + 1`，其他快捷键请自行查看软件设置，常用的在截图时也会显示。

### 剪贴板：

Windows 自带剪贴板重启后消失，大文件不显示，没有搜索，总而言之不好用。（观前严肃提醒，剪贴板和输入法是隐私泄露两巨头，不管手机电脑）

剪贴板工具我推荐两个，第一个是 Ditto，极致的轻量，完全开源免费，数据完全存储在本地，但是 UI 比较古老，且不支持 Win + V 作为快捷键，另一个就是 EcoPaste，确实会占用更高，但换来的是美观的 UI 和一键使用 Win + V，而且隐私泄露方面做的极好，内置 Secrets 识别引擎，当复制 API Keys、JWT Token、私钥或从 1Password/Bitwarden 复制密码时，可配置为自动抹除/脱敏保存或忽略。大家自行比对后使用。

[Ditto 官网](https://sabrogden.github.io/Ditto/) ，[Ditto GitHub 下载](https://github.com/sabrogden/Ditto/releases/tag/3.25.113.0) ，[EcoPaste 官网](https://www.ecopaste.cn/) ，[EcoPaste GitHub 下载](https://github.com/EcoPasteHub/EcoPaste/releases/tag/v1.1.0) 。
