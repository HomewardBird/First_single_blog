## 前言
（书写时间为2026.7，知识部分未来短时间内大概通用，但型号推荐仅供参考）

装过台式机的朋友，大概都体验过挑选主板、CPU、显卡等配件时的纠结；哪怕是电脑小白，多半也刷到过“5060”之类的配置字眼。

这篇博客不想去卷各大品牌的跑分对比，只想用通俗的语言，带你搞懂每个部件到底是干嘛的，以及如何判断好坏——**防止去电脑城或者网购时，被黑心老板当肥羊宰。** 至于更为详尽的科普笔者考虑在“学有余力”篇进行科普。          

至于本篇所有硬件书写格式大多都为*知识科普，挑选建议，使用时注意事项* 进行书写。

### 主板

主板主板，顾名思义，就是一块板子，你的绝大部分电脑配件都安装在上面，外设（除了显示器）一般也与他相连。

#### 基础功能：
（可以理解成军事基地）
1. 提供场地（即物理载体，否则你的配件怎么固定呢）
2. 后勤保障（即供电，主板上有复杂的供电模块（VRM））
3. 交通公路（即数据通路，主板上密密麻麻的电路）

由于主板知识较为复杂，在此不过多赘述（好奇者可查看硬件杂谈相关视频）      
新手要注意的就是这块主板与你的CPU与是否兼容，内存条插槽为DDR4还是DDR5，以及芯片组的档次（笔者推荐大部分人购买B系列，除非预算极低或极高）


### CPU

非常重要的配件，沿用刚才的军事比喻的话就类似于将军，负责战术计算，核心决策 ~~（怪不得人家中文名叫中央处理器）~~ 。总而言之就是给所有硬件下达命令的。

虽然 CPU 看着是一块板，实则不然。它内部是由多个核心组成的，“双核”、“四核”就是指它的核心数。   

核心越多，工作效率肯定越快……吗？实则不然。在架构相同的前提下，我们可以简单套用一个粗暴的公式：**性能 = 核心数 $\times$ 主频**。（只是类比，实际比这复杂得多）有时候 $10 \times 1 < 1 \times 100$ 的道理大家都懂。 为了防止核心多但全在“摸鱼”，就有了 “主频” 的概念。它代表 CPU 的时钟频率（CPU内部的数字信号每秒钟震荡的次数，也就是CPU工作的速度）。        

若核心大小不同，则被称为大小核，可以更好平衡性能和功耗，Windows11系统就针对大小核有专门的优化。还有一个概念叫线程数，也就是能同时处理多个任务。

并不是说核心数越多、主频越高的处理器性能就一定强，这在实际应用中是一个十分复杂的综合平衡关系。
#### 常见型号：

两家厂商都很有默契地把产品分成了 3、5、7、9 四个档次（类似宝马的3系、5系、7系）：
1. **入门/办公**：i3 / R3（注：AMD 的 3 系列近几年在零售市场存在感较低）
2. **主流游戏/高性价比**：i5 / R5 / Ultra 5（目前两家都在打架的主战场）
3. **高端生产力/发烧友**：i7 / i9 / R7 / R9


#### **防坑指南：**   
不要盲目迷信数字！**并不是叫 i7 就一定强于 i5。** 电子产品买新不买旧，隔代如隔山。拿好几年前的老旧 i7 去碰瓷今年的最新款 i5，只会被沦为路边一条。

至于之前让人诟病的 i9-13900K/14900K 闪退风波，懂的都懂，新手不碰顶配基本踩不到这个雷，在此不作展开


#### **装机注意事项：** 
1. 注意与主板是否匹配，这两家CPU主板不互通。
2. 有防呆设计（防止你装反），所以发现放不进去时，请去检查是不是没有对准，不要大力出奇迹弄坏针脚。
3. 注意撕膜，CPU散热器（即风冷 or 水冷）底座有层膜，不撕无法散热，CPU温度会异常。
4. CPU 表面必须涂抹适量导热硅脂，这玩意 *“当你觉得少了点“*  说明刚好，笔者一般是九点涂法（点九个小点）
5. 如果买了带有 **F** 尾缀（如 i5-14400F）或者无核显的旧款 AMD 处理器， **必须要额外购买独立显卡** 且显示器与独立显卡连接，否则无法亮屏（显卡篇具体解释）

### 内存条（RAM）

笔者写下此篇时，由于AI的原因，内存条和金条一样贵，令人感慨。话说回来，内存条类似军营中传令兵，负责把将军马上要用的文件和命令临时放在身边，方便随时调阅。（务必注意，RAM内存条断电就会失去一切存储信息，和硬盘（SSD/HDD）不同）        

内存条（RAM）比较重要的概念笔者认为是世代代号（DDR）和工作频率（MHz）。它们决定了内存与 CPU 之间的数据传输带宽。带宽越大，数据送达 CPU 的速度就越快，不仅能防止 CPU 闲置“发呆”，还能显著提升游戏的最低帧（1% Low 帧），让游戏画面减少突然的卡顿。
#### 作用：

1. 临时数据中转站：由于下文介绍的硬盘（SSD/HDD）速度较慢，CPU来不及处理的数据，就先暂时存放在此。
2. 决定处理多任务的能力：相信大家买手机都有 “16+512” 这种选项，虽然手机厂商在你那512GB存储空间不够时也会说 “内存不足” ，但请读者理解，电脑上的内存就是指前面的16，大家之所以要买大内存的手机，应该是为了游戏，微信，QQ，挂后台不被手机 “杀” 了，正是因为内存条在后台把这些程序的运行数据同时 “兜住” 。


#### 产品迭代：

1. 低频 DDR4（如 2133MHz、2400MHz）及更早的 DDR3，若不是读者有意购买，那就是被老板坑了，旧时代的电子小垃圾。
2. 若为老电脑或预算低，高频DDR4可以考虑，技术极其成熟，价格已经跌到谷底，时序（延迟）非常低。但是上限被锁死，其他配件也注定落后。
3. 大部分人的选择应该是DDR5内存，这个主要看个人预算，**以及和主板的适配性** ~~（笔者这位憨批买了8000MHz的内存条，但主板这么高频率容易崩，只能退回7200MHz）~~ 

#### 小贴士：

1. 现在内存条大多购买两根，**千万不要买两个工作频率不同的内存条！** 电脑只会向下兼容。
2. 内存条组装时也有防呆设计，请勿大力出奇迹。
3. 装机时请插入2,4通道，**绝对不能乱插** 
4. 笔者个人推荐若日常使用，16GB内存就够用，若有更高的需求，如生产力，游戏，那建议32GB以上。至于运行频率，6000MHz - 6800MHz完全够用。
5. 电脑到手重启时狂按Delete（不同主板方式可能不同，如联想为F1，惠普为F10，若不确定，可询问客服 or 售后）进入bios界面，开启 XMP / EXPO，否则内存条频率会自动降低，白花钱购买高频率内存条。

### 显卡（GPU）
（显卡知识较多）

终于来到了常规电脑中最贵的一部分了（从严格定义来讲 GPU 不等于显卡， GPU 属于显卡的一个组成部分，但笔者认为这是无意义的咬文嚼字），继续用兵营式比喻就类似于冲锋骑兵，负责大规模冲锋，即图像渲染和大计算量工作，大家在部分软件（如Wallpaper Engine）中见到的“硬件加速”就是指使用显卡加速。

再说到另一个极其重要的概念——显存。当 GPU 在疯狂计算时，数据是怎么来的呢？ CPU 靠内存条提供，而GPU就靠显存，所以可以将显存理解为专属于显卡的高速内存。此外，显卡算完的每一帧画面，在真正显示到你屏幕上的前一秒，都必须暂存在显存的“帧缓冲区”，若显存太小，可能导致游戏画面瞬间卡成幻灯片、动态贴图变马赛克、甚至游戏直接闪退。（共享显存≠独立显存，前者速度较慢）    

还有一个概念叫位宽，单位为bit。严谨概念为“在一个时钟周期内能够同时传输的二进制数据位数”，大家可以把显卡理解成仓库，位宽就是出入口个数，八个出入口肯定不如十六个出入口对吧。所以不要看到16GB显存就认为是好显卡，仓库大小固然重要，但只有一个出入口啥用没有。（当年市场上的RTX 3060 12GB和RTX 3060 8GB。8G 版本不只是显存小了，它的显存位宽也被硬生生阉割了一截，所以买卡看清具体规格参数，不能只看型号的前半截或者只看显存）

显卡有集成显卡（简称为核显或集显）和独立显卡（简称为独显）的区别，前者就是将 GPU 整合在 CPU 内部，性能较差，后者就是大家常见的一长条的形式，将GPU独立出来，性能较好。

现在显卡主要厂商有两家分别是英伟达（NVIDIA），超威半导体（AMD），也是俗称的“绿厂”和“红厂”。（还有英特尔（Intel）和中国的摩尔线程等，但笔者认为新手没必要购买红绿厂之外的显卡，故不过多赘述）     

（笔者建议大家使用显卡支架，防止显卡下垂或插槽变形，当然假如你不想买，拿个裁剪到合适长度的一次性筷子或橡皮也是可以的，但比较难刚好卡住）

>现在互联网上总给人一种人均4090,5090的错觉，仿佛别的显卡都不配叫显卡一样，笔者劝大家莫要盲目购买高配置，按照需求和预算来永远是最好的。毕竟真正使用人数最多的还是3060。

#### 产品选择：
（这一块每个人有各自看法，笔者只是给出我的观点，欢迎在评论区讨论）

1. 1080P区 ~~（注：这是指分辨率而不是人数）~~：假如预算有限，显示器分辨率也不高，可以购买RTX 3060 12G / RTX 4060 / RX 6600。（3060是真好用）

### 硬盘（HDD/SSD）

又到了一个最近死贵的硬件了，还记得之前的内存条中提到的 “16+512” 的例子吗，其中的 512GB 在电脑中就是归硬盘管的。用来存储数据，类似军营中存放武器的仓库。断电了其中的数据也不会消失（严格来说，不论是固态还是机械，很长时间不通电数据依然会丢失，所以加入一个硬盘中存储着重要数据记得每年拿出来通电一下）

硬盘分为两种，机械硬盘（hard disk drive，即常说的HDD）内部有高速旋转的金属/玻璃盘片（涂有磁性介质）和极其精密的磁头。抗震性差，噪音和功耗大，数据可恢复性较强，容量大，价格低，速度慢。      

固态硬盘（solid state drive，即常说的SSD）内部没有任何物理机械运动部件，主要由主控芯片和闪存芯片组成。抗震性强，噪音和功耗小，数据几乎不能恢复，容量小、价格高、速度较快。        

若预算高直接全上固态即可，但若预算并不是那么充足，可以考虑采用固态 + 机械的思路，各取所长。
